# zvrtsh

Игра в которой игрокам предстоит отвечать на вопросы друг друга, зная при этом 
лишь часть вопроса.

**Содержит в себе не самые лучшие практики написания кода.**

### Запуск сервера:

Добавить `config/.env`, соответствующий схеме 
[config/.env.dist](config/.env.dist)

```bash
docker-compose up
```

### Запуск клиента на винде:

```bash
./bin/cli-win.exe
```

### Запуск клиента не на винде:

```bash
./bin/cli-linux
```
